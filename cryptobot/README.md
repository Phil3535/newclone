# CryptoBot Pro - Trading Bot SaaS Platform

## Overview
CryptoBot Pro is a subscription-based trading bot platform that allows users to automate their cryptocurrency trading on Crypto.com exchange.

## Features
- Smart Trading Strategies (Grid, DCA, Trend Following)
- Crypto.com Exchange Integration
- User Dashboard for Bot Management
- Admin Dashboard for Revenue Tracking
- Stripe Payment Integration
- 3 Subscription Tiers: Basic ($29), Pro ($59), Elite ($99)
- 7-Day Free Trial

## Tech Stack
- **Backend**: FastAPI (Python)
- **Frontend**: React
- **Database**: MongoDB
- **Trading**: CCXT Library (Crypto.com)
- **Payments**: Stripe
